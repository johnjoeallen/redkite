# Analysis History

RedKite keeps the 7 most recent analyses per project, not just the latest one — older scans are pruned automatically as new ones complete. The project dashboard's **Analysis history** list shows those past runs with their timestamp and status badge (complete, failed, or partially complete) — click any row to open that specific analysis exactly as it looked when it ran.

This is what lets you re-run an analysis after applying changes and compare the before/after directly: applying a set of changes automatically triggers a fresh analysis (see [Apply Selected](../applying-changes/apply-selected.md)), and the previous analysis stays in the history for reference rather than being overwritten.
