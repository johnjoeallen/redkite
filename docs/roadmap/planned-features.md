# Planned Features

None of these exist yet. Each links to its own page with more detail on what's actually there today and what the planned capability would add.

- **[Parent and Ancestor Updates](../recommendations/parent-and-ancestor-updates.md)** — recommending an update to a direct dependency, BOM, or parent POM as an alternative to a direct pin on a transitive dependency
- **[Minimum Upgrade Policy](../recommendations/minimum-upgrade-policy.md)** — a configurable policy for how far an automatic recommendation is allowed to move
- **[CVE Ranking](../vulnerabilities/cve-ranking.md)** and **[Candidate Comparison](../vulnerabilities/candidate-comparison.md)** — see [Advanced CVE Resolution](advanced-cve-resolution.md)
- **[Future config.rk](../configuration/future-config-file.md)** — a project-local configuration file, checked in alongside the project's own POM

If you're evaluating RedKite for a use case that depends on one of these, it's worth confirming directly rather than assuming — this list reflects the current codebase, not a committed timeline.
