# Vulnerabilities

RedKite checks every dependency it discovers — direct and transitive — against known CVE data, and folds fixable findings into its recommendations.

- **[OSV Data](osv-data.md)** — where the vulnerability data comes from and how it's cached
- **[Severity Levels](severity-levels.md)** — how RedKite classifies and ranks a finding's severity
- **[CVE Ranking](cve-ranking.md)** *(planned)* — how competing findings will be weighed against each other
- **[Candidate Comparison](candidate-comparison.md)** *(planned)* — how candidate fix versions will be compared beyond severity alone
- **[Limitations](limitations.md)** — what this checking does not cover

See also [Vulnerability Fixes](../recommendations/vulnerability-fixes.md) for how a found CVE turns into an actual recommendation.
