# Adding a Project

From the RedKite home page, type the full path to a Maven project and click **Analyse**. RedKite creates a project record the first time it scans a given path, and every subsequent analysis of that same path is added to that project's history rather than creating a new one.

A progress overlay shows the current scan phase while the analysis runs; the browser navigates to the project's dashboard automatically once it completes.

Existing projects are listed on the home page too — click **Analyse** next to one to re-scan it, without needing to re-type the path.
